The one word we'd erase from the dictionary forever. The program writes one word to `/output/entry.txt`:

> forever

Why this word: the deletion undoes itself — erase "forever" and nothing can last forever, including the erasure. The brief itself says "erase from the dictionary forever", so the joke lands the instant the word is read. Seventeen hand-written candidates were scored 0–5 on the judge brief (how fast the joke lands, how much of it comes from the word itself, how fresh the pick is); "forever" scored a perfect 15/15, ahead of "yes" and "right" at 14. The field is saturated with irregardless, moist, queue, literally, colonel, tomorrow and lisp — all of those scored fresh 1–2 and lost.

## Run it

```sh
node main.ts
```

Node 22, standard library only. Deterministic: no randomness, no network, no input files.
